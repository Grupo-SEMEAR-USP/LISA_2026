# Bem vindo ao repositório da LISA! # 

A LISA (Levando Imapcto Social Adiante) é a nossa robô humanoide, desenvolvida pelo Grupo SEMEAR, da Escola de Engenharia de São Carlos (EESC-USP).

Neste repositório estão reunidos todos os códigos, documentações e materiais relacionados ao desenvolvimento da LISA.

## 🎯 Objetivos

O projeto busca desenvolver um robô capaz de:

- 🤖 Interagir com pessoas de forma natural;
- 👀 Reconhecer pessoas e objetos utilizando visão computacional;
- 🗣️ Responder a comandos de voz;
- 😊 Expressar emoções através de movimentos da cabeça, braços e expressões visuais.
